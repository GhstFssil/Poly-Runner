# Poly Run

A single-file 3D platformer (three.js r128) with an embedded Path Editor and Rig Editor. Open `checker-run.html` in a browser (it loads three.js from a CDN). See `ARCHITECTURE.md` for how the pieces fit together and `SWEEP-BUGS.md`, `SWEEP-EDGES.md` and `SWEEP-PERF.md` for the nightly sweeps.
